# Atividade — página de atendimento de um consultório

Crie uma página para um consultório fictício. A página deverá apresentar uma
orientação ao paciente e um formulário de solicitação de atendimento.

Use o [exemplo do kit](exemplo/index.html) como referência, mas escolha o nome,
os textos e as cores do seu consultório.

## Onde salvar

No seu repositório privado de Web 1, crie:

```text
atividades-iniciais/
└── atividade-01-html-css-grid/
    ├── index.html
    └── styles.css
```

## Requisitos essenciais

1. Use a estrutura básica do HTML e ligue um arquivo CSS externo.
2. Organize a página com `header`, `main`, pelo menos duas `section` e `footer`.
3. Em uma seção, apresente informações úteis para o paciente.
4. Na outra, crie um formulário com pelo menos cinco campos, rótulos ligados
   aos campos e um botão. Inclua nome, uma forma de contato e o atendimento
   desejado.
5. Use no CSS pelo menos um seletor de elemento, um de classe e um de
   identificador.
6. Transforme o conteúdo principal em Grid com duas colunas e espaço entre
   elas.
7. Use margem, preenchimento e borda para deixar o conteúdo organizado e
   legível.

O formulário demonstra somente a estrutura visual. Não é necessário salvar ou
processar os dados.

## Resultado esperado

Ao abrir `index.html`, a página deve mostrar um cabeçalho, dois blocos de
conteúdo lado a lado, um formulário utilizável e um rodapé. O CSS deve carregar
sem erros, e os textos devem permanecer fáceis de ler.

## Critérios de correção

Será possível observar se:

- os dois arquivos estão na pasta solicitada e ligados corretamente;
- a estrutura HTML usa os elementos pedidos e não possui etiquetas abertas;
- cada campo possui um rótulo claro com `for` e `id` correspondentes;
- os seletores de elemento, classe e identificador funcionam;
- o Grid cria duas colunas no conteúdo principal;
- margem, preenchimento, borda, cores e texto mantêm a página legível;
- os textos e dados do consultório foram adaptados pelo estudante.

## Melhorias opcionais

Depois de atender aos requisitos essenciais, você pode:

- usar uma regra `@media` para mostrar uma coluna em tela pequena;
- incluir uma terceira seção com horários de atendimento;
- ajustar a paleta de cores, mantendo bom contraste entre texto e fundo.

As melhorias opcionais não fazem parte da correção dos requisitos essenciais.
