Prioridades no CSS

Abra o arquivo styles.css, altere a ordem das regras e observe o resultado.

1. Seletor mais específico

Este texto fica vermelho porque o seletor de ID é mais específico.

p → .mensagem → #aviso-principal

2. Mesma especificidade

Este fundo fica verde porque a regra verde aparece depois.

.mesma-prioridade → .mesma-prioridade

3. Contexto aumenta a especificidade

Este texto fica azul porque .painel .nota é mais específico que .nota.

4. Exceção: !important

O roxo vence o ID por causa de !important.

Use apenas para estudar o mecanismo; evite como solução habitual.
